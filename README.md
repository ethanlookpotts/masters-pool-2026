# 2026 Masters Pool Leaderboard

A real-time, mobile-optimized leaderboard for the 2026 Masters Tournament pool.

## Features
- **Live Scoring:** Fetches real-time data directly from the ESPN PGA API.
- **Projected Prizes:** Calculates winnings based on live tournament positions and Augusta-style tie-splitting rules.
- **Live Scorecards:** Expandable team cards showing hole-by-hole progress for all rounds.
- **Zero Backend:** Pure HTML/CSS/JS implementation that runs entirely in the browser.

## Contents
- `index.html` / `style.css` / `app.js`: The core application.
- `masters-2026-strategy.md`: Original draft strategy and pool results.
